# 智能协同云图库 Logo 设计规范

## 目标

为“智能协同云图库——一个基于 Vue 3 的海量免费图片获取平台”设计一套现代、简洁、可缩放的矢量 Logo，用于网站导航栏、favicon、应用图标和品牌展示。

## 核心概念

Logo 使用“云朵＋图片画框”的融合图形：

- 云朵表示云端存储、海量资源和协同能力。
- 图片画框及其中的太阳、山峰表示图片获取与图库业务。
- 云朵和画框共用视觉轮廓，使图标紧凑统一，而不是两个图形的简单拼接。
- 图形保持较少细节，确保缩小到 favicon 尺寸后仍然清晰可辨。

## 视觉语言

- 风格：现代、清爽、轻量、圆润。
- 主色：科技蓝 `#1677FF`。
- 辅色：Vue 绿 `#42D392`。
- 彩色版本使用蓝绿渐变。
- 默认背景透明。
- 不使用阴影、复杂纹理或 AI 电路线，以保证小尺寸清晰度和跨场景适用性。

## 构图

### 纯图标

使用近方形画布。主体由以下元素组成：

1. 云朵上轮廓；
2. 圆角图片画框；
3. 小圆点太阳；
4. 简化山峰曲线。

图形应在画布中留出安全边距，避免用作 favicon 或圆形头像时被裁切。

### 横版品牌标志

横版由左侧纯图标和右侧文字组成：

- 主标题：“智能协同云图库”；
- 副标题：“海量免费图片获取平台”；
- 紧凑场景可隐藏副标题，仅保留图标和主标题。

文字采用系统无衬线字体栈，避免依赖额外字体资源。

### 单色图标

单色版本使用 SVG `currentColor`，用于：

- 深色模式；
- 菜单图标；
- 水印；
- 无法使用渐变的印刷或嵌入场景。

## 交付物

- 透明背景纯图标 SVG；
- 横版品牌 SVG；
- 使用 `currentColor` 的单色 SVG。

所有 SVG 均应：

- 具备明确的 `viewBox`；
- 支持无损缩放；
- 包含可访问的 `title`；
- 使用唯一且有语义的渐变 ID，降低嵌入页面后的 ID 冲突概率；
- 不引用外部图片、字体或样式资源。

## 验收标准

- 能直观联想到“云端图库”。
- 颜色能够体现 Vue 生态和智能云服务。
- 在浅色背景上具备良好对比度。
- 纯图标在 16×16 至 32×32 像素范围仍能辨认主体轮廓。
- 横版适合网站导航栏和品牌介绍区域。
- 单色版可通过 CSS `color` 属性切换颜色。
