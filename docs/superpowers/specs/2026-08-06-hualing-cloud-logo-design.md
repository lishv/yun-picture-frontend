# 绘灵云图片协作平台 Logo 设计规范

## 目标

为“绘灵云图片协作平台”建立具有名称关联和独立剪影的正式品牌标志。新版从汉字“绘”提炼专属几何结构，不再使用通用云朵、图片框、应用底板、走势折线或 AI 风格符号。

## 品牌结构

- 品牌主名：绘灵云
- 产品说明：图片协作平台
- 页面完整名称：绘灵云图片协作平台
- 横版组合：`[几何绘字标志] 绘灵云 / 图片协作平台`

## 核心标志：隐字成标

标志采用实心几何色块重构“绘”的关键骨架：

- 左侧三块递进的斜切画带提取“纟”的笔画关系，表达绘制过程、素材流动和多人参与；
- 右上人字形色块提取“会”的顶部结构，代表成员与创意相遇；
- 中部两条宽阔横向色块既构成“会”的字形骨架，也隐喻图片画幅；
- 下方汇聚色块完成“会”的收束结构，表达共同完成作品；
- 左右部件在中心交叠关联，使标志可隐约识别为“绘”，但不直接使用现成字体。

## 造型语言

- 采用实心几何色块，不使用描边；
- 采用斜切、梯形和紧凑负空间，形成独有剪影；
- 使用透明背景，不设置圆角方形、圆形或其他应用图标底板；
- 主图标使用 64×64 画布并保留安全边距；
- favicon 使用 32×32 专门简化的相同结构；
- 图形不出现云朵、山景、星光、节点、折线图或装饰纹理。

## 配色

- 深海蓝：`#123B5D`——“会”的主体骨架，表达正式、稳定和可信赖；
- 灵感青：`#34B6A8`——左侧“纟”形画带，表达创作、流动和灵感；
- 墨色：`#172733`——横版 Logo 主标题；
- 灰蓝：`#637987`——横版 Logo 产品说明。

独立彩色标志只使用深海蓝和灵感青。禁止渐变、阴影、发光、霓虹和蓝紫色科技效果。

## 资源版本

### 彩色独立标志

- 透明背景；
- 三块灵感青“纟”形画带；
- 一块深海蓝人字顶；
- 两块深海蓝横向画幅；
- 一块深海蓝下部汇聚结构；
- 不含文字、矩形底板或描边。

### 单色标志

- 所有几何部件均使用 SVG `currentColor`；
- 不使用白色或十六进制硬编码颜色；
- 适合菜单、水印、深色模式和单色印刷。

### favicon

- 使用 32×32 简化几何“绘”字；
- 保持透明背景和双色实心结构；
- 加粗并放大关键色块，保证 16×16 下轮廓稳定；
- ICO 内含 16×16、32×32、48×48 三个真实子图。

### 横版 Logo

- 图标位于左侧；
- “绘灵云”使用 `#172733`、700 字重；
- “图片协作平台”使用 `#637987`、400 字重并增加字间距；
- 使用系统无衬线字体栈，不加载外部字体。

## 工程约束

- 所有 SVG 包含 `viewBox`、非空 `title`、`role="img"` 和匹配的 `aria-labelledby`；
- SVG 不引用外部脚本、图片、字体或样式；
- 彩色版本不使用渐变；
- 单色版本只使用 `currentColor`；
- favicon.ico 是真实多尺寸 ICO；
- 不修改页面布局、路由、接口或业务逻辑；
- 当前项目不是 Git 仓库，不执行 Git 操作。

## 验收标准

- 标志具有可关联“绘灵云”的几何“绘”字骨架；
- 独立剪影清楚，不依赖应用底板；
- 不再呈现普通图片框或数据走势图外观；
- 不包含 AI、魔法、机器人、星光、电路或霓虹元素；
- 横版 Logo 完整显示“绘灵云”和“图片协作平台”；
- 页头 48px 和 favicon 16×16 下均保持清晰；
- SVG、ICO 与 HTML 接入自动化检查全部通过。
