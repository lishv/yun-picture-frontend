# 智能协同云图库 Logo 优化设计规范

## 目标

重新设计“智能协同云图库”品牌 Logo，解决原图标在浏览器标签页中尺寸过小、白色画框过于突出、云朵特征不清晰的问题。新版需同时适用于 16×16 favicon、ICO、多尺寸网站图标、导航栏及横版品牌展示。

## 视觉方向

采用“蓝紫云境”风格：

- 主色起点：`#397BFF`；
- 主色终点：`#7C4DFF`；
- 图形前景：白色；
- 风格：醒目、现代、智能、简洁；
- 默认背景：图标自身具有圆角方形蓝紫底板，确保在浅色和深色浏览器标签栏中均有稳定轮廓。

## 图标构图

### 底板

- 使用正方形画布和约 22% 的圆角矩形底板。
- 蓝紫渐变由左上方向右下方过渡。
- 底板覆盖大部分画布，仅保留约 2 像素视觉安全边距。
- 不使用阴影、纹理、透明玻璃效果或复杂高光。

### 核心符号

核心符号使用大面积白色图形，将云朵与图片山峰融为一个符号：

- 上半部分使用简化云朵轮廓；
- 下半部分以山峰负形或切口表达图片属性；
- 删除原设计中的独立白色图片画框；
- 删除小太阳，避免 16×16 下形成噪点；
- 使用粗轮廓、宽间距及尽量少的控制点；
- 不添加文字、字母或细线装饰。

## 尺寸策略

### 16×16 与 32×32

- 使用专门简化的 favicon 几何；
- 优先保证云朵外形和山峰切口清晰；
- 不依赖不足 1 像素的线条；
- 四周保留安全边距，避免浏览器缩放时触边。

### 64×64 及更大尺寸

- 品牌图标与 favicon 保持一致的轮廓和配色；
- 可使用更平滑的曲线，但不增加新的装饰元素；
- 确保不同尺寸显示为同一品牌符号。

## 横版品牌标志

横版 Logo 由新版图标和文字组成：

- 主标题：“智能协同云图库”；
- 副标题：“海量免费图片获取平台”；
- 主标题使用深蓝紫色，突出品牌关联；
- 副标题使用低饱和灰蓝色；
- 字体采用系统无衬线字体栈，不加载外部字体；
- 横版 Logo 不用于 favicon。

## 单色版本

- 使用 SVG `currentColor`；
- 保留新版圆角底板及融合符号的基本关系；
- 通过实色底板配合反向留白或轮廓表达符号；
- 不包含蓝紫色或其他硬编码品牌色；
- 用于菜单、深色模式、水印及单色印刷。

## 交付物

- `src/assets/branding/cloud-gallery-icon.svg`：新版 64×64 彩色品牌图标；
- `src/assets/branding/cloud-gallery-icon-mono.svg`：新版单色品牌图标；
- `src/assets/branding/cloud-gallery-logo-horizontal.svg`：新版横版 Logo；
- `public/favicon.svg`：浏览器优先使用的简化 SVG favicon；
- `public/favicon.ico`：包含 16×16、32×32 和 48×48 图像的兼容 ICO；
- `index.html`：优先引用 SVG favicon，并保留 ICO 兼容声明。

## HTML 接入

页面标题继续使用“智能协同云图库”。favicon 声明按以下顺序配置：

1. `image/svg+xml` 的 `/favicon.svg`；
2. `/favicon.ico` 作为旧浏览器兼容资源。

浏览器可能缓存旧 favicon，验收时应强制刷新或清除该站点缓存。

## 工程约束

- SVG 必须包含 `viewBox`、可访问的 `title`、`role="img"` 和正确的 `aria-labelledby`；
- 每个彩色 SVG 使用不同的渐变 ID，防止内联组合时冲突；
- SVG 不加载外部脚本、图片、样式或字体；
- ICO 必须是真实多尺寸 ICO 文件，而不是仅修改扩展名；
- 不修改 Vue 页面、路由或业务逻辑；
- 更新现有 Logo 契约测试以覆盖新颜色、favicon 与 HTML 引用。

## 验收标准

- 在 16×16 浏览器标签页中能清楚辨识为云朵图标，而不是白色图片框；
- 蓝紫底板在浅色与深色标签栏中均醒目；
- 山峰切口不会在 16×16 下变成无意义噪点；
- SVG 与 ICO 使用一致的品牌视觉；
- ICO 包含 16、32、48 三种尺寸；
- 横版 Logo 的中英文标点和中文文案完整显示；
- 页面仍显示标题“智能协同云图库”；
- 自动化资源契约测试全部通过。
